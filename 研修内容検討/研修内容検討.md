## ハンズオン

### 方針

- 文字量多いプロンプトは資料に書いて受講者がコピペできるようにしておく
- 使用技術
  - **HTML + CSS + JavaScript** のシンプルな構成
  - ローカル実行は VSCode の **Live Server** プラグインで Web を立ち上げる

### 内容サマリ

- 基本操作方法
  - ３つのモード
    - コードの調査・実装計画・コードレビュー等のファイルを編集してほしくないタスクをお願いするとき等に以下設定を切り替える
    - Ask before edits: ファイル編集やコマンド実行の前に毎回ユーザーへ許可を求めるデフォルトモード
    - Edit automatically: 作業ディレクトリ内のファイル編集や基本的なファイル操作コマンドを自動承認するモード
    - Plan mode: 読み取り・調査のみ行い、実装前に計画を提示してユーザー承認を得るモード
  - Effortとは: モデルが推論(思考)にかける深さを制御する設定。low/medium/high/max があり `/effort` で切替(Opus 4.6 のデフォルトは high)
- 開発開始
  - CLAUDE.md
  - 開発プロセスルールを決める
- 開発時便利機能
  - MCP連携
  - @ファイル名
  - スラッシュコマンド
    - /btw：会話履歴に追加せずに、現在のセッションについてのサイド質問ができるコマンド。メインの作業スレッドを汚さずに確認・質問ができ、引数なしの /btw で直近のサイド質問を振り返れます。Claudeが回答生成中でも /btw を実行でき、サイド質問は独立して動作しメインタスクを中断しない
